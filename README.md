GimMutatio

Estudiante: Naizeth Belen Vargas Ramos

Descripción del proyecto

GimMutatio es un sistema web inteligente orientado a la gestión administrativa y financiera de un gimnasio. Permite organizar la información de los clientes, membresías, pagos y asistencias, además de facilitar la consulta de reportes y análisis para apoyar la toma de decisiones.

Objetivo

Mejorar la organización y el control de las actividades administrativas y financieras del gimnasio mediante un sistema web.

Proyecto académico

Desarrollado como parte de la evaluación continua del Hito 3.
